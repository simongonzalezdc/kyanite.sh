# Enhancement #2: Rapid Prototyping Mode
**LyricForge - First Draft Speed Optimization**

**Version:** 2.0  
**Date:** October 17, 2025  
**Owner:** Simon (Kyanite)  
**For:** Kilocode AI-assisted implementation  
**Purpose:** "Make your first draft almost type" - eliminate friction between idea and lyrics

---

## Executive Summary

Transform LyricForge from a comprehensive songwriting suite into a **speed-first rapid prototyping tool** by adding a dedicated "Sketch Mode" that prioritizes momentum over completeness. Users should go from idea to first draft in <60 seconds.

**Core Principle:** Get words on screen fast, polish later.

---

## User Stories

### Story 1: Instant Start
**As a** songwriter with sudden inspiration  
**I want** to start writing within 30 seconds of having an idea  
**So that** I don't lose momentum or creative flow

**Acceptance Criteria:**
- [ ] Launch app and be writing within 30 seconds
- [ ] No required metadata/forms before writing
- [ ] Theme-based quick start available
- [ ] First line suggested by AI instantly

### Story 2: Continuous Flow
**As a** songwriter in the middle of writing  
**I want** to get unstuck instantly when ideas dry up  
**So that** I maintain creative momentum

**Acceptance Criteria:**
- [ ] Single hotkey generates next line
- [ ] Multiple variations available to choose from
- [ ] Suggestions match context and style
- [ ] Response time <2 seconds

### Story 3: Low-Commitment Experimentation
**As a** songwriter trying rough ideas  
**I want** to write without saving everything  
**So that** I can experiment freely without cluttering my library

**Acceptance Criteria:**
- [ ] Default to unsaved "scratch pad"
- [ ] Explicit action required to save
- [ ] Can discard drafts easily
- [ ] No guilt or friction around deletion

---

### 1. Quick Start Command
**Priority:** P0 (Critical)  
**Effort:** Medium (3-5 days)

**CLI Addition:**
```bash
# Launch directly into editor with AI brainstorm
$ lyricforge quick "lost my dog"

# Or just start blank
$ lyricforge quick
```

**Behavior:**
1. Skip main menu entirely
2. Open editor in scratch mode (unsaved)
3. If theme provided:
   - Stream 3 angle suggestions to AI panel
   - User picks with 1/2/3 key
   - AI generates opening line in editor
4. If no theme:
   - Blank editor, cursor ready
   - Type theme inline, AI watches

**Implementation Notes:**
```go
// cmd/lyricforge/main.go
var quickCmd = &cobra.Command{

    Short: "Start writing immediately",
    Args:  cobra.MaximumNArgs(1),

            ScratchMode: true,
            Theme: theme,
            AutoBrainstorm: theme != "",

        p := tea.NewProgram(model, tea.WithAltScreen())
        p.Run()
    },
}
```

```go
type EditorModel struct {
    // ... existing
    scratchMode bool
    saved       bool
}

// On Ctrl+K
func (m EditorModel) keepDraft() (EditorModel, tea.Cmd) {
    // Prompt for title if empty
    if m.song.Metadata.Title == "" {
        return m.showTitlePrompt()
    }
    
    // Save to database + filesystem
    err := m.editorService.SaveSong(m.song)
    if err != nil {
        return m.showError(err)
    }
    
    m.scratchMode = false
    m.saved = true
    
    return m, m.showNotification("Saved to library!")
}

// On quit
func (m EditorModel) onQuit() tea.Cmd {
    if m.scratchMode && !m.isEmpty() {
        // Show confirmation
        return m.showDiscardConfirmation()
    }
    return tea.Quit
}
```

### 7. Fast Quality Check
**Priority:** P1 (High)  
**Effort:** Medium (3-4 days)

**Current:** 7-dimension quality rubric (detailed)
**New:** 3-tier quality system

**Sketch Mode - Red Flags Only:**
- [ ] >10 clichÃ©s
- [ ] No concrete imagery (all abstract)
- [ ] Major rhyme scheme breaks

**Draft Mode - Basic Quality:**
- [ ] ClichÃ© count
- [ ] Imagery ratio
- [ ] Meter consistency
- [ ] Rhyme accuracy

**Polish Mode - Full Critique:**
- [ ] All 7 dimensions
- [ ] Line-by-line feedback
- [ ] Actionable suggestions

**Implementation:**
```go
type QualityCheckMode int

const (
    CheckRedFlags QualityCheckMode = iota  // Sketch
    CheckBasic                              // Draft
    CheckFull                               // Polish
)

// In quality agent
func (a *QualityAgent) RunCheck(song *domain.Song, mode QualityCheckMode) (*QualityReport, error) {
    switch mode {
    case CheckRedFlags:
        return a.checkRedFlags(song)
    case CheckBasic:
        return a.checkBasic(song)
    case CheckFull:
        return a.checkFull(song)
    }
}

func (a *QualityAgent) checkRedFlags(song *domain.Song) (*QualityReport, error) {
    report := &QualityReport{}
    
    // 1. ClichÃ© count
    cliches := a.detectCliches(song)
    if len(cliches) > 10 {
        report.AddFlag("Too many clichÃ©s detected", High)
    }
    
    // 2. Imagery check
    imageryRatio := a.calculateImageryRatio(song)
    if imageryRatio < 0.3 {
        report.AddFlag("Needs more concrete imagery", High)
    }
    
    // 3. Rhyme breaks
    breaks := a.detectRhymeBreaks(song)
    if len(breaks) > 3 {
        report.AddFlag("Rhyme scheme inconsistent", Medium)
    }
    
    return report, nil
}
```

**Priority:** P2 (Medium)  
**Effort:** Small (1-2 days)

```go
// In Update()
case tea.KeyMsg:
    if msg.String() == "ctrl+shift+c" {
        content := m.song.ToMarkdown()
        clipboard.WriteAll(content)
        return m, m.showNotification("Copied to clipboard!")
    }
    
    if msg.String() == "ctrl+shift+e" {
        return m.showExportDialog()
    }
    
    if msg.String() == "ctrl+shift+o" {
        editor := os.Getenv("EDITOR")
        if editor == "" {
            editor = "vim"
        }
        
        // Save to temp file
        tempFile := filepath.Join(os.TempDir(), m.song.Metadata.Title+".md")
        m.song.SaveToFile(tempFile)
        
        // Open in editor
        cmd := exec.Command(editor, tempFile)
        return m, tea.ExecProcess(cmd, func(err error) tea.Msg {
            return ExternalEditCompleteMsg{err: err}
        })
    }
```
