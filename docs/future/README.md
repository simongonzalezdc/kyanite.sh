## Collaboration Feature

The collaboration system is fully implemented but currently disabled via feature flag. It's designed for future expansion when multi-user functionality is needed.

**Current Status:** Code complete, disabled by default for single-user mode.

**To Enable:** See [collaboration.md](collaboration.md) for configuration instructions.

## Adding New Future Features

When planning a new feature:

1. Create a design document in this folder
2. Document the feature's purpose and user stories
3. Include technical architecture considerations
4. Note any dependencies or prerequisites
5. Keep separate from archived/completed work

## Note

These are **actively planned** features, not abandoned work. For historical documentation of completed features or deprecated approaches, see [../archive/](../archive/).
