# kyanite.sh

Unified suite of terminal-first creative tools (focus, noise, syntax, prism) built with Go and Charm.

**Who it is for:** people who want small, focused TUI utilities instead of a bloated creative suite.

**What you get:** Go sources for the kyanite.sh tool family.

## Quick start

```bash
git clone https://github.com/simongonzalezdc/kyanite.sh.git
cd kyanite.sh
go build ./...
# run individual tool mains as documented in cmd/ or tool dirs
```

- Charm/TUI patterns follow each tool's own help text
