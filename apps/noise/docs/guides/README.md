## Quick Reference

### Voice Dictation
Press `Ctrl+D` to start/stop voice recording. Models download automatically on first use.

### PWA Sync
Enable in config, generate pairing code, connect from your phone.

### Themes
Press `Ctrl+Shift+T` to cycle themes, or create custom themes in `~/.config/noise/themes/`.
