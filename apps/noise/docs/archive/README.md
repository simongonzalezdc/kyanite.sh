```
archive/
├── specifications/           # Original design documents
├── enhancements/            # Completed enhancement specs
├── implementation-reports/   # Historical implementation details
├── legacy/                  # Old/superseded documents
└── deprecated.md            # Deprecation notices
```

## Why Archive?

Documents are archived when they:
1. Describe completed work (implementation reports)
2. Contain superseded designs (legacy specs)
3. Are no longer accurate but provide historical context
4. Have been replaced by current documentation

## Contributing to Archive

When archiving documents:
1. Move to the appropriate subfolder
2. Do not modify content (preserve historical accuracy)
3. Update this README if adding new categories
4. Reference the archive from current docs if relevant
